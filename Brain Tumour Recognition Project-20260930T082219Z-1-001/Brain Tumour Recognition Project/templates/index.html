03 / READ BEFORE USING

A model output is
not a medical answer.

This classifier is a student project for learning and demonstration. It has not been established as safe or effective for diagnosis, screening, or treatment decisions.

The displayed score is the model's raw sigmoid output. It is not a calibrated probability, and performance on these examples may not reflect performance on other scanners, populations, or image types.
